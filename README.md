# PokiClash ⚔

Juego de estrategia en tiempo real 100% web, inspirado en Clash Royale clásico.

## 🚀 Despliegue en GitHub Pages
1. Sube estos archivos a tu repositorio.
2. Entra en **Settings > Pages**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Abre la URL asignada y juega directamente desde cualquier dispositivo.
